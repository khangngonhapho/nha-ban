# US-132: Phân giải Đánh số Thứ tự Ảnh và Hiển thị Đồng nhất trên Trang Chi tiết Khách hàng

## User story
**As an** Admin
**I want** các hình ảnh được hiển thị đồng nhất về cả số thứ tự sequence ID trên slide biên tập và thứ tự/số lượng hiển thị trên trang chi tiết khách hàng theo đúng `Images_Public_JSON`.
**So that** khách hàng nhìn thấy đúng các hình ảnh tôi đã chọn lọc và sắp xếp, đồng thời tôi dễ dàng theo dõi số thứ tự ảnh đang biên tập.

## Acceptance
- [x] Khi click "👁️ Hiện" từng hình trong Editor, hiển thị số thứ tự sequence ID `#1`, `#2`, ... tự động tăng dần ở góc trên bên phải của slide ảnh lớn trong Editor.
- [x] Số thứ tự sequence ID trên slide ảnh phải trùng khớp hoàn toàn với số thứ tự hiển thị trên thumbnail strip phía dưới.
- [x] Trang chi tiết khách hàng và Preview chi tiết khách hàng trong Editor phải hiển thị danh sách hình ảnh trùng khớp 100% về cả số lượng lẫn thứ tự đã biên tập (đọc từ `Images_Public_JSON` thay vì trộn lẫn `poolImgs` lên trước).

## Solution

> [!note]- Input
> - `editPublicInteriorIndices`: danh sách index ảnh nội thất public dạng chuỗi phân tách bởi dấu phẩy.
> - `editPublicAlleyIndices`: danh sách index ảnh hẻm public dạng chuỗi phân tách bởi dấu phẩy.
> - `Images_Public_JSON` trên tab Source (Google Sheets).

> [!note]- Key logic
> - Hàm `getPublicImagesFromForm` được cập nhật để phân giải URL hình ảnh từ:
>   1. `window.imageEditorSlides` (Editor đang sửa)
>   2. `p.curated_config.images` (Ảnh Cloudinary đã lưu)
>   3. `poolRowData` (Ảnh thô)
> - Lưu trữ thuộc tính `images_public` (chứa mảng ảnh được parse từ `Images_Public_JSON`) trong đối tượng listing `p` tại `lego_core.js`.
> - `lego_detail_client.js` và `lego_render_client.js` ưu tiên đọc `p.images_public` làm nguồn hình ảnh chính.
